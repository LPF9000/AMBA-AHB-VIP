# Contributing

This project is in its initial setup stage. Please start changes on a feature
branch and use a pull request when the change is ready for review. Direct
commits to main are not part of the workflow.

Read the [roadmap](ROADMAP.md) before proposing a feature. Protocol changes
should name the applicable Arm specification revision, describe the supported
configuration, and include focused tests with reproducible seeds. Report which
checks ran and any simulator or integration paths that remain untested.

Write documentation in clear, natural language and keep support claims tied
to implementation and test evidence. Update the roadmap when milestones change.

The `aidocs/` directory is available for local working notes. Its contents are
ignored, apart from the file that preserves the directory in Git. Agent
instructions and AI tooling configuration also stay local.
