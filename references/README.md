# Reference catalogs

These catalogs collect public standards, manuals, tool documentation, and verification examples relevant to this VIP. They link to source pages and describe each reference's role and access conditions. The repository does not redistribute these documents.

Local working copies of standards and manuals are kept separately in ignored `aidocs/references/`; they are private workspace files and are not linked as repository assets.

- [UVM methodology references](UVM/README.md)
