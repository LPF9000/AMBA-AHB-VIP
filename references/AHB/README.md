# AHB-Lite references

The current implementation baseline is Arm IHI 0033A, AMBA 3 AHB-Lite. This catalog links to the revision-specific source and the official AMBA index.

- [Arm IHI 0033A documentation page](https://developer.arm.com/documentation/ihi0033/a) — official Arm page for revision A, marked superseded in Arm's version selector. Arm provides a PDF download from the page without a listed purchase price; the page may redirect through Arm's current support site.
- [Arm AMBA specifications](https://www.arm.com/architecture/system-architectures/amba/amba-specifications) — official index of AMBA specifications and protocol families. Use IHI 0033A for the behavior of this repository's current profile.

The local IHI 0033A PDF is a workspace-only copy under ignored `aidocs/references/AHB/`; the specification is not included in this repository.
